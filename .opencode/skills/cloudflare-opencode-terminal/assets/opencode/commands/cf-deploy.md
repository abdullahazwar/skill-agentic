Muat skill cloudflare-opencode-terminal. Lakukan deployment dalam scope berikut:

$ARGUMENTS

Tentukan akun, Worker, environment, branch dan resource dari config atau hasil alat. Jika target produksi/staging belum dapat ditentukan, lakukan persiapan lokal yang aman lalu minta informasi target. Jalankan validasi dan dry-run, pertahankan data, deploy, lalu periksa health, URL dan deployment ID. Jangan menganggap perintah ini memberi izin hapus database, ubah billing atau kirim pesan produksi.
