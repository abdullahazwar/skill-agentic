# Sumber resmi dan pemutakhiran

Tanggal pemeriksaan awal: 17 Oktober 2026, Asia/Jakarta.

Gunakan file ini sebagai indeks penemuan. Tidak semua halaman dan tautan di bawah telah diperiksa baris demi baris. Buka halaman topik saat mengandalkan detailnya. Dokumentasi terbaru dan schema versi terpasang mengungguli contoh skill.

## Urutan sumber

1. Dokumentasi resmi produk dan changelog.
2. Schema Wrangler yang terpasang dan help CLI.
3. Tipe hasil wrangler types.
4. Respons API akun yang sedang dipakai.
5. Panduan ini sebagai workflow, bukan kontrak harga permanen.

Gunakan alat docs Cloudflare bila tersedia. Jika tidak, buka developers.cloudflare.com dan cari halaman produk yang tepat. Jangan memakai salinan preview dokumentasi sebagai rujukan final bila halaman resmi tersedia.
