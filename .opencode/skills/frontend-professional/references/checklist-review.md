# Review frontend

- [ ] Alur utama selesai dan kontrol sesuai label.
- [ ] Identitas dan urutan konten memiliki alasan sesuai produk.
- [ ] Tidak ada klaim, testimoni atau angka nyata yang dikarang.
- [ ] Demo dan batas integrasi disebut jelas.
- [ ] Type, alignment, spacing, density dan media konsisten.
- [ ] Desktop, mobile dan breakpoint berubah sudah diperiksa.
- [ ] Semantik, label, keyboard, focus, contrast dan reflow diperiksa sesuai scope.
- [ ] State penting ditangani tanpa menghapus input/data valid.
- [ ] Angka, periode, mata uang, filter dan ekspor konsisten jika ada.
- [ ] Tidak ada secret atau kepercayaan client menggantikan validasi/izin backend.
- [ ] Cek proyek relevan lulus atau kegagalannya dicatat akurat.
- [ ] Screenshot dilihat dan interaksi dicoba jika browser tersedia.
- [ ] Asal dan lisensi aset/kode upstream ditinjau.
- [ ] Diff mempertahankan perubahan pengguna dan scope.
- [ ] Handoff menyebut hasil, tes nyata dan batas yang material.

Checklist ini alat review, bukan sertifikat kualitas/kepatuhan otomatis.
